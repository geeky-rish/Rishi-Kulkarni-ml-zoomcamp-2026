# ML Zoomcamp 2026

My work and learning journey through the **DataTalks.Club Machine Learning Zoomcamp 2026**.

- Writing the code myself rather than relying on libraries blindly
- Building reproducible ML workflows
- Completing hands-on assignments and projects
